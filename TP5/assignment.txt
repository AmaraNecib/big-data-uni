1. Educational Objectives 
Understand the role of Apache Kafka in distributed event-streaming architectures. 
Distinguish Kafka brokers, topics, partitions, producers, consumers, and consumer groups. 
Deploy a single-node Kafka broker in KRaft mode using Docker Compose. 
Develop a Python producer that publishes simulated sensor events to a Kafka topic. 
Develop a Python consumer that reads events, parses JSON messages, and performs simple real-time analysis. 
Observe message flow, consumer offsets, and basic fault/debugging behavior. 
2. Scenario and Problem Statement 
A smart-campus monitoring system generates temperature and humidity readings continuously. Storing readings only in static 
files delays analysis and makes it difficult for multiple applications to consume the same events. In this lab, students will  
simulate sensor devices, stream JSON events through Apache Kafka, and build a consumer that reports measurements and 
detects high-temperature events. The data are synthetic and are used only for educational purposes.

7. Task 3 — Create the Producer 
Create producer.py. It generates one synthetic sensor event every second and sends it to the campus-sensors topic. 
import json 
import random 
import time 
from datetime import datetime, timezone 
from kafka import KafkaProducer 
 
TOPIC = "campus-sensors" 
 
producer = KafkaProducer( 
    bootstrap_servers="localhost:9092", 
    value_serializer=lambda value: json.dumps(value).encode("utf-8"), 
    acks="all", 
) 
 
try: 
    for event_id in range(1, 31): 
        event = { 
            "event_id": event_id, 
            "sensor_id": f"sensor-{random.randint(1, 4):02d}", 
            "temperature_c": round(random.uniform(18, 42), 2), 
            "humidity_pct": round(random.uniform(25, 85), 2), 
            "timestamp": datetime.now(timezone.utc).isoformat(), 
        } 
        producer.send(TOPIC, value=event)

8. Task 4 — Create the Consumer and Analyze the Stream 
Create consumer.py. It reads the events, displays each measurement, and flags temperatures of 35°C or higher. 
import json 
from kafka import KafkaConsumer 
 
TOPIC = "campus-sensors" 
 
consumer = KafkaConsumer( 
    TOPIC, 
    bootstrap_servers="localhost:9092", 
    auto_offset_reset="earliest", 
    enable_auto_commit=True, 
    group_id="tp05-campus-monitor", 
    value_deserializer=lambda value: json.loads(value.decode("utf-8")), 
) 
 
print(f"Listening to topic: {TOPIC}") 
try: 
    for message in consumer: 
        event = message.value 
        temperature = event["temperature_c"] 
        print( 
            f'{event["timestamp"]} | {event["sensor_id"]} | ' 
            f'T={temperature}°C | RH={event["humidity_pct"]}%' 
        ) 
        if temperature >= 35: 
            print("ALERT: High temperature detected!") 
except KeyboardInterrupt: 
    print("Consumer stopped by user.") 
finally: 
    consumer.close() 
Open Terminal 2 and start the consumer before running the producer:
